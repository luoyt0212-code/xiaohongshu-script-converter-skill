# 口播脚本转小红书文案 Skill

把中文视频口播稿、录音转写稿、粗糙观点笔记，整理成适合小红书/RedNote 发布的图文内容，并生成 3-6 张统一风格配图。

这个仓库是 YouMind skill「口播脚本转小红书文案V2.0」的作者提供 prompts 版本，适合放到 Claude、Codex 或其他支持 `SKILL.md` 的 agent 工作流中使用。

## 能做什么

- 压缩口播稿里的重复、跑题和口头禅
- 将内容压缩到原文约 50%
- 保留全部核心知识点和并列要点
- 转成适合小红书的标题、分段正文和小标题
- 固定追加 AI 创投圈引流结尾
- 生成 3-6 张简约杂志风小红书配图
- 给出封面图、观点卡片、金句/行动建议图的生成 prompt

## 适合场景

- 短视频口播稿转小红书图文
- 会议/录音转写内容再加工
- 知识分享、教程讲解类内容二次分发
- 投资人、创始人、知识博主的观点内容沉淀
- AI、商业、投资、个人成长类内容的小红书发布

## 安装方式

把本仓库放到你的 agent skills 目录中，例如：

```bash
~/.codex/skills/xiaohongshu-script-converter/
```

或：

```bash
~/.claude/skills/xiaohongshu-script-converter/
```

确保目录内包含：

```text
SKILL.md
README.md
examples/
```

## 使用示例

你可以这样触发：

```text
把下面这段口播脚本转成小红书文案，并生成系列配图：

【粘贴口播稿】
```

也可以指定风格：

```text
请把这段知识分享口播稿压缩成 50% 左右，保留所有并列要点，转成小红书图文。
```

## 输出结构

默认输出：

1. 小红书标题
2. 分段正文与小标题
3. 固定 AI 创投圈结尾
4. 3-6 张系列配图
5. 每张配图对应的生成 prompt

## 视觉风格

默认配图采用简约杂志风：

- 3:4 竖版，1080x1440px
- 米白色或浅灰色背景
- 深炭灰主文字
- 单一强调色
- 大量留白
- 网格化布局
- 每张图文字量控制在 50-100 字
