# 口播脚本转小红书文案 Skill

把中文视频口播稿、录音转写稿、粗糙观点笔记，整理成适合小红书/RedNote 发布的图文内容。

这个仓库是一个可分享的开源版 skill，适合放到 Claude、Codex 或其他支持 `SKILL.md` 的 agent 工作流中使用。

## 能做什么

- 压缩口播稿里的重复、跑题和口头禅
- 提炼一个更适合传播的核心观点
- 生成 5 个标题备选
- 输出小红书正文
- 给出封面图和轮播图建议
- 生成适合图片模型使用的配图 prompt
- 补充标签和不同风格的改写方向

## 适合场景

- 短视频口播稿转小红书图文
- 会议/录音转写内容再加工
- 投资人、创始人、知识博主的观点内容沉淀
- AI、商业、投资、个人成长类内容的二次分发

## 安装方式

把本仓库放到你的 agent skills 目录中，例如：

```bash
~/.codex/skills/xiaohongshu-script-converter/
```

或：

```bash
~/.claude/skills/xiaohongshu-script-converter/
```

确保目录内包含：

```text
SKILL.md
README.md
examples/
```

## 使用示例

你可以这样触发：

```text
把下面这段口播脚本转成小红书文案，并给我封面图和轮播图建议：

【粘贴口播稿】
```

也可以指定风格：

```text
请用投资人视角，把这段录音稿改成专业但不自吹的小红书文案。
```

## 输出结构

默认输出：

1. 核心提炼
2. 标题备选
3. 小红书正文
4. 配图建议
5. 标签
6. 可选改写方向
